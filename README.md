# Medical Billing — American Billing Solutions

Next.js website for [American Billing Solutions](https://americanbillingsolutions.com).

## Quick start

```bash
cd frontend
npm install
npm run dev
```

Or from the repo root:

```bash
npm install
npm run dev
```

## Structure

```
frontend/   # Next.js 15 App Router application
```

## Production

```bash
cd frontend
npm run build
npm run start
```
